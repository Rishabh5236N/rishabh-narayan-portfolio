# Rishabh Narayan Portfolio

Creative portfolio for Rishabh Narayan, focused on entertainment marketing, agency advertising, social and digital growth, brand strategy, behavioral marketing, content creation, and audience research.

## Live Site

[rishabh-narayan-portfolio.pages.dev](https://rishabh-narayan-portfolio.pages.dev)

## Deployment

This repository contains the static, Cloudflare-ready website bundle:

- `index.html` contains the portfolio experience.
- `assets/` contains local images, documents, and optimized media.
- `_headers` contains Cloudflare Pages response-header rules.

The site can be deployed directly from the repository root with no build command.
